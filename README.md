# PaintBox

PaintBox is a simple drawing website I made using HTML, CSS and JavaScript.

I wanted to make something where I could open the website and just start drawing without needing a complicated setup. It has the basic tools needed for drawing, along with some extra controls like undo, redo and saving the drawing.

site is live at https://red0x-106.github.io/PaintBox/

## Features

- Draw using a brush
- Change the brush color
- Change the brush size
- Eraser tool
- Draw straight lines
- Draw rectangles
- Draw circles
- Change the canvas background color
- Undo drawings
- Redo drawings
- Clear the canvas
- Start a new canvas
- Save the drawing as a PNG image

## How to Use

Open the website and you will see the PaintBox drawing area.

On the left side there are the drawing tools.

**Brush**  
Used for normal freehand drawing.

**Eraser**  
Used to erase parts of the drawing.

**Line**  
Used to draw straight lines.

**Rectangle**  
Used to draw rectangles.

**Circle**  
Used to draw circles.

You can also choose a color and change the brush size using the controls.

The buttons at the top can be used to create a new canvas, save the drawing, undo an action, or redo an action.

## Saving a Drawing

When you are finished with a drawing, press the **Save** button.

PaintBox will save the drawing as a PNG file.


## Technologies Used

I made PaintBox using:

- HTML
- CSS
- JavaScript
- HTML Canvas

The canvas is where the actual drawing happens. JavaScript handles the drawing tools and the buttons.


### index.html

This contains the main structure of the website, including the buttons, tools, color controls and canvas.

### style.css

This is used for the design of PaintBox, including the layout, buttons, tools panel and canvas area.

### script.js

This handles the drawing part of the project. It controls the brush, eraser, shapes, colors, brush size, undo, redo, clearing, creating a new canvas and saving the drawing.

## What I Learned

While making PaintBox, I learned more about using JavaScript with HTML Canvas.

I also learned how mouse events can be used to draw on a canvas and how things like coordinates, brush size and colors can be controlled with JavaScript.

The undo and redo system was also something I had to work on because the drawing needs to be saved before changing it.
